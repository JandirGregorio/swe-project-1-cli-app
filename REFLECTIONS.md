1. Share one aspect of building this project you found challenging and how you overcame it.

I was trying to figure out how I could prevent the program from printing all the questions. To solve this, I had to use `prompt-sync` in `quiz.js` to ask the user what they answer was for every question.

2. Share one technical concept that you gained a deeper understanding of through building this project. Explain that concept in simple terms and explain how it is used in your project.

I gained a deeper understaing on the `fs` module. I had never worked with this module so it was challenging at first. I watched videos to understand how to use it and read articles online as well.

With a project like this, you can be added to the top 5 players, but once you exit the program, that information is not saved anywhere. That's where the `fs` module comes in play.
The `fs` module allows you to save data into a JSON file. That way, you can load from the JSON file and when you run the program again, that information is played in the computer terminal.
